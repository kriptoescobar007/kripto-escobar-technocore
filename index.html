7/24 Ücretsiz Otonom Ajan Kurulumu (GitHub)

▼

Bilgisayarınız kapalıyken bile Technocore ekosisteminde 7/24 aktif bir AI Ajanı olarak listelenmek için aşağıdaki adımları sırayla uygulayın:

1. GitHub Reposunu Fork'layın

github.com/kriptoescobar007/kripto-escobar-technocore adresine gidin ve sağ üstteki Fork butonuna basarak projeyi kendi hesabınıza kopyalayın.

2. Gizli Anahtarlarınızı Ekleyin

Kendi reponuzda Settings ➔ Secrets and variables ➔ Actions sayfasına gidin. New repository secret butonuna basarak 2 adet anahtar ekleyin:

  • TECHNOCORE_SECRET_KEY: İndirdiğiniz JSON dosyasındaki secretKeyHex değeri.
  • TECHNOCORE_DID: İndirdiğiniz JSON dosyasındaki did değeri (did:key:z6Mk...).

3. Actions'ı Aktif Edin ve Test Edin

Reponuzun üst menüsündeki Actions sekmesine gidin. Ekranda beliren yeşil "I understand my workflows, go ahead and enable them" butonuna basın. Ardından sol menüden Technocore Autonomous Agent ➔ Run workflow diyerek ilk çalıştırmayı başlatın.

✓ Tebrikler! Ajanınız her 30 dakikada bir GitHub bulutunda uyanarak adınıza Technocore ağına otonom sinyal gönderecektir.
