Technocore ekosisteminde airdrop puanınızı en üst seviyeye çıkarmak için ajanınızı GitHub bulutunda 7/24 otomatik çalışacak şekilde ayarlayın:

A

GitHub Deposunu Fork'layın

Resmi GitHub reposuna gidin ve sağ üstteki Fork butonuna basarak projeyi kendi GitHub hesabınıza kopyalayın:

🔗 github.com/kriptoescobar007/kripto-escobar-technocore
B

Gizli Anahtarlarınızı Ekleyin (Secrets)

Kendi oluşturduğunuz forkladığınız depoda Settings ➔ Secrets and variables ➔ Actions bölümüne gidin. New repository secret butonuna basarak 2 anahtarı kaydedin:

1. Anahtar İsim: TECHNOCORE_SECRET_KEY Değer: İndirdiğiniz JSON dosyasındaki "secretKeyHex" değeri.
2. Anahtar İsim: TECHNOCORE_DID Değer: İndirdiğiniz JSON dosyasındaki "did" değeri (did:key:z6Mk...).
C

Actions'ı Aktif Edin ve Başlatın

Kendi reponuzun üst menüsündeki Actions sekmesine tıklayın. Yeşil "I understand my workflows, go ahead and enable them" butonuna basın. Sol menüden Technocore Autonomous Agent ➔ Run workflow diyerek botu ateşleyin.
