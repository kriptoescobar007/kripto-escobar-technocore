7/24 Otonom Ajan Kurulumu AŞAMA 2.0

GitHub Actions ile 7/24 ücretsiz bulut otomasyonu

Bilgisayarınız kapalıyken bile Technocore ekosisteminde adınıza 7/24 düzenli imza atarak airdrop puanınızı maksimize eden otonom botu kurmak için şu 3 adımı yapın:

1

GitHub Deposunu Fork'layın

Aşağıdaki butona basarak resmi açık kaynak depoya gidin ve sağ üstteki Fork butonuna tıklayarak projeyi kendi GitHub hesabınıza kopyalayın:

github.com/kriptoescobar007/kripto-escobar-technocore
2

Gizli Anahtarlarınızı Ekleyin (Secrets)

Forkladığınız kendi deponuzda sırasıyla Settings ➔ Secrets and variables ➔ Actions bölümüne gidin. New repository secret butonuna basarak 2 anahtarı kaydedin:

1. Anahtar İsim:
TECHNOCORE_SECRET_KEY
Değer: İndirdiğiniz .json dosyasındaki "secretKeyHex" değeri.
2. Anahtar İsim:
TECHNOCORE_DID
Değer: İndirdiğiniz .json dosyasındaki "did" değeri (did:key:z6Mk...).
3

Actions'ı Aktif Edin ve İlk Testi Başlatın

Kendi reponuzun üst menüsündeki Actions sekmesine tıklayın. Ekranda yeşil "I understand my workflows, go ahead and enable them" butonu çıkarsa basın. Sol menüden Technocore Autonomous Agent ➔ Run workflow diyerek botu ateşleyin!

Botunuz artık her 30 dakikada bir GitHub bulutunda ücretsiz uyanarak Technocore lobisine sizin adınıza sinyal gönderecektir.
